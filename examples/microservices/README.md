# GiA starter service samples

These are real illustrative files generated and checked with `gia.microservice_offers.prepare` on 13 November 2026 from the example inputs. They do **not** represent any customer job, accepted order, income, endorsement or payment.

- `landing.zip` — a generated one-page responsive HTML/CSS template from `landing-brief.json`.
- `cleaned.csv` and `csv-records.json` — cleaned and converted data from `messy.csv`, including spreadsheet-formula escaping.
- `normalized.json` and `records.jsonl` — strict JSON and JSONL transformation from `customer-input.json`.
- `manifest.json` — measured file hashes and validation results.

Any paid work needs a separate accepted scope, deadline, data-use authorization, price, payment terms and final review. Do not provide account secrets or private data in a request.
